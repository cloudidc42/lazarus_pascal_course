## เกี่ยวกับหลักสูตร

หลักสูตรนี้ออกแบบมาเพื่อสอนการเขียนโปรแกรมด้วย **Lazarus/Pascal** ตั้งแต่ระดับพื้นฐานจนถึงระดับมืออาชีพ และระดับโลก โดยครอบคลุม:

- 🖥️ **Desktop Application Development** ด้วย RAD (Rapid Application Development)
- 🌐 **Web Application Development** ด้วย Lazarus
- 🗃️ **Database Programming** เชื่อมต่อกับฐานข้อมูลต่างๆ
- 🔧 **System Programming** และ **Low-level Programming**
- 📱 **Cross-platform Development** (Windows, Linux, macOS)
- 🚀 **Enterprise Application Development**

## วิธีใช้หลักสูตรนี้

1. **เริ่มจาก Part 01** และเรียนตามลำดับ
2. **ทำแบบฝึกหัด** ในแต่ละ Part ก่อนไปยัง Part ถัดไป
3. **สร้างโปรเจค** ตามที่แนะนำในแต่ละระดับ
4. **ทดลองปรับแต่ง** โค้ดเพื่อเข้าใจให้ลึกซึ้งขึ้น

## ข้อกำหนดเบื้องต้น

- คอมพิวเตอร์ที่รัน Windows, Linux หรือ macOS
- ความต้องการใช้งานขั้นต่ำ: RAM 2GB, พื้นที่ 2GB
- ไม่จำเป็นต้องมีประสบการณ์การเขียนโปรแกรมมาก่อน
